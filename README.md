# 南科大校园面板

基于固定版本的 [sustech_survival](https://github.com/dumixthestpd/sustech_survival)。支持 Windows 本机客户端和用户自己的 Linux 常开服务器，两种模式共用同一套功能。每个实例独立保存一个用户的凭据和校园数据，直接连接学校系统。

安装与运行见 [客户端说明](CLIENT-README.md)，更新、签名与维护流程见 [UPDATING.md](UPDATING.md)。源码公开，可 fork 后自行部署；凭据、校园数据、运行数据库和下载文件均不在仓库中。

**0.5.12 Windows 已正式发布并与本机同步。**交作业面板新增 PDF 预览，使用与题目册、答案册相同的浏览器阅读方式。[公共入口](https://124.221.144.155/app/) 仅提供静态发布与帮助。当前 Windows 构建、公开升级及本机实测见[0.5.12 验收记录](docs/RELEASE-0.5.12-ACCEPTANCE.md)，历史迁移见[阶段验收记录](docs/LOCAL-MODE-ACCEPTANCE.md)。当前 Linux 分发目标保留为 0.5.9。

完整范围、迁移和服务器资源清理见 [第二阶段总计划](docs/WEB-HOSTED-PLAN.md)，新 Thread 从 [执行交接](docs/LOCAL-MODE-HANDOFF.md) 开始。取消集中托管后保留本地缓存和文件复用，跨用户共享服务退役，见 [复用与下载规则](docs/SHARED-METADATA-AND-DOWNLOADS.md)。

既有 0.3.5 可用 `campus-client.exe --local-only` 进入本机设置并检查签名更新。[第一阶段记录](docs/HOSTED-PHASE1.md)保留历史实现与验收，不作为继续扩建托管的计划。旧数据迁移、服务停止和资源删除须分别有实际回读证据。

## 每日概览与课表

- 显示今日课程、校历放假及调休安排、未提交作业与剩余时间、考试和待评教。
- 调休信息之后提供默认折叠的本周课表：七日网格、课程颜色、教室、节次、实际时段，保留周末补课。
- 校历由 [sustech-calendar](https://github.com/dumixthestpd/sustech-calendar) 的日期引擎计算。假期、停课日与期末期间不显示常规课程，补课使用对应原日期的周次与单双周；校历失败时显示未知，不退回普通星期推断。
- Blackboard 使用 TIS 当前学期标识，并按校历自动确定日期范围；作业与资料采用相同范围。读取失败保留最近成功数据并显示错误。

## Blackboard 作业

每条作业均可展开，显示描述与要求、教师附件、允许尝试次数、提交记录、成绩和反馈、官方页面可读信息与接口元数据。已提交附件从官方提交页面提取，可经私人接口下载。

选好 PDF 后，文件行右侧提供“预览”，在新标签页打开原生 PDF 阅读器。预览后已选文件仍保留，可继续核对或提交。

普通个人作业在官方允许提交时提供拖拽文件框、正文、注释和右下角提交按钮。每次最多 20 个不同文件名的文件，总大小不超过 255 MB。点击提交使用同一登录会话中新读取的官方提交表单与 nonce；不重试写入。只有提交状态及所选文件均回读匹配才确认成功。网络或回执不明确时锁住重复请求并显示待核对。

已提交作业不会覆盖；官方已有草稿附件时保留草稿，提示到原页面继续。测验和小组作业显示可读信息并链接官方页面，不使用个人作业上传入口代替答题或小组提交。页面本身不判断文件是否符合教师要求。

本机“自动制册”可从课程资料和公告定位教材，提取题目并生成题目册、作答册和答案册。每门课程首次分别确认教材题号和三册 PDF，之后处理后续新作业；不会自动提交。运行条件与边界见[作业工作流](docs/HOMEWORK-WORKFLOW.md)，当前本机测试状态见[作业验收记录](docs/HOMEWORK-ACCEPTANCE-20261012.md)。

## 场地与预约

- 主页面统一列出图书馆及 E-Hall 场地；可预约场地提供按钮，进入同一架构的下一层页面。
- 讨论间合为一个入口，详情页按官方容量 **1–3 人 / 3–7 人** 分两栏。查询今天至后天的开放与占用安排。
- 可先指定日期和完整目标时段，筛选全程空闲场地，再选房间。改查询时段会使旧查询失效，提交前重新检查。
- 可搜索共同申请人，本人自动加入；按官方人数、开放时间、单次时长与提前预约规则校验。
- E-Hall 使用官方活动类型和活动方式字典，支持申请资料附件。空闲以官方实时检查为准，占用清单仅含当前账户可见记录。
- 我的预约支持日期与官方状态查询，按可用权限显示取消、修改、提前结束、续时等操作。续时先查询官方允许时长；写入回读后才确认，需审批的预约仍以官方审批结果为准。
- **讨论间后台监控已撤销**：独立服务停止且禁止开机启动，旧监控 API 返回 410。已有预约不受影响。

## 课程附件

展开课程后，课程公告显示在该课程资料列表顶部；正文保留格式与附件链接，默认折叠长正文。附件使用学校公告页面给出的权限地址，由本人实例下载，避免 REST 原始 XID 链接返回无权限。没有公告的课程不显示空公告区域。跨课程正文、链接、视频等内容检索从本分区进入。

按课程查看；网页先打开学校下载指引。学校会话失效时在官方内容页登录，再下载到浏览器目录。自动按课程归档、批量下载和失败重试由自己的本机组件完成，组件用本机校园凭据直接连接学校。

自动保存新资料默认关闭，启用后每 5 分钟扫描并处理新可见附件。首次成功扫描为当前用户建立基线；既有用户更新保留其真实基线，历史验收中的附件数量不是固定初始化常数。手动批量请求可包含旧资料并跳过已核验保存的文件。尚未开放目录显示访问限制，之后开放时算新可见资料。

文件按用户选择的根目录、课程及 Blackboard 目录保存；0.3.4 起使用规范化文件名，仅在必要的同名目录处使用稳定标识。组件原子保存并记录来源版本、大小与 SHA-256；重复任务核验已有文件，学校新版另存，用户修改文件不覆盖。已保存资料提供文件/文件夹打开入口，文件缺失或变化显示真实状态。

旧托管已退役。关机期间不再有运营者代为发现资料或排队；本机恢复后重新同步，保留的基线和完成回执继续使用。

## 成绩、打印、选课与空闲教室

- 首页三个统一入口：成绩与学分、校园打印、选课辅助。空闲教室归入场地与预约。
- 成绩仅显示当前学期的记录，提供学期筛选、课程搜索、在修学分、通过学分和 CSV 导出。参考 GPA 优先使用 TIS 返回值；等级、百分制、通过制及重修按学校学生手册区分。未知计分制、特殊成绩不冒算官方累计 GPA。
- 打印提供打印点、待打印和扫描文档、按日期和类型查询使用记录，以及文件上传、份数/色彩/纸张/单双面/页码设置。删除先显示文档名和不可恢复说明；上传及删除回读官方队列后确认。文件只在请求期间暂存，结束即清理。**PMS 仍受校园网或学校 VPN 可达性限制；2026-10-07 本机实际只读查询成功，公网请求由所属执行电脑处理。网络受限时会明确显示未连接，不能冒充空队列或成功上传。**
- 选课支持全校目录与本人本轮可选课程、教师/类别/语言筛选、已选课与官方购物车、按周次和节次检测冲突、最多八门课程的备选排课，以及使用同一放假/调休规则的已选课 ICS 导出。跨年校历不可用时仅导出已知年份，在文件名及页面中标注截止日期。页面核对后可选入、退课、增删购物车和逐课程更新积分；提交前重查窗口与权限，不忽略冲突和容量规则。每次写入只发一次，官方记录未匹配时保留待核对状态。
- 空闲教室按日期、节次、地点和已知容量筛选；假期抑制常规课程，调休使用原课程日期。临时借用按实际日期处理。教务系统不返回场地编码时显示“借用待核验”，不能把上游空数组当作已确认空闲。借用申请从选定教室进入，预览并重查权限和占用后发送；申请回执不等于审批通过。
- 新接口按需读取，不阻塞首页 Blackboard 和资料同步。未验证正式选退课、积分更新、打印上传或删除；这些操作只在用户点击并核对后执行。

## 运行与存储

增量服务已包含在 0.5.4 预览版，本机功能验收通过；原稳定更新源仍为 0.4.3。服务集中在“校园服务 → 更多服务”：校巴班次/实时位置/地点与路线估算、牛蛙社区评分与评论、CLE 指导时段及本人预约、国际交流项目、教师目录与研究方向、图书馆文献检索，以及大纲、培养方案、手册与地图镜像。首页仍保留原来的三张服务卡片。Blackboard 本人列成绩折叠在“成绩与学分”，免交状态用于作业列表；正式评教从已有“待评教”进入。本机功能、独立标准用户及分发验收边界见[增量验收记录](docs/INCREMENTAL-SERVICES-ACCEPTANCE-20261012.md)。

CLE、图书馆检索和正式评教使用随程序分发的 Playwright 驱动及设备上已安装的 Google Chrome；使用独立无界面会话，不连接用户浏览器配置。Linux 可通过 `SUSTECH_BROWSER_EXECUTABLE` 指定浏览器。缺少浏览器时明确提示，不把错误显示成空结果。评教逐题由用户填写；预约、取消、保存、正式提交及教室申请均先显示具体预览，再由用户确认，未知回执不自动重发。精确步行导航在上游停用，面板提供的站点连接估算不代表实际道路。

```powershell
pwsh -NoProfile -File 'D:\Projects\SUSTechCampusDashboard\dashboard.ps1' start
pwsh -NoProfile -File 'D:\Projects\SUSTechCampusDashboard\dashboard.ps1' status
pwsh -NoProfile -File 'D:\Projects\SUSTechCampusDashboard\dashboard.ps1' bookings
```

Windows 的 `start` / `serve` 默认启动本机客户端；`open-server` 只接受已有的用户自有服务器配置。旧运营者配对在解密和联网前被拒绝。旧 Windows 登录任务 `SUSTechCampusDashboard` 保持停用，新的客户端后台启动仅按用户选择登记。

维护者本机数据位于 `D:\AppData\SUSTechCampusDashboard`，依赖环境在 `D:\Caches\SUSTechCampusDashboard-venv`。分发版在没有 D 盘的 Windows 设备使用当前用户数据目录。凭据使用 Windows DPAPI，仅在当前用户进程内解密，更新与迁移不得重置既有基线和下载文件。

原拥有者服务与从零重建记录见第一阶段交付；运营者托管空间与相关业务 API 已退役。项目独占服务、程序、状态及旧备份已在迁移和恢复核验后从服务器移除，恢复材料受限保留在维护者 D 盘；静态发布/更新、共享 nginx/TLS 和其他网站继续运行。旧讨论间监控保持撤销。

运行快照、凭据、基线、下载资料、数据库及日志均不进入 Git。上游固定提交 `acd20323af6d3bc91c3e89974283d39d85109678`。
