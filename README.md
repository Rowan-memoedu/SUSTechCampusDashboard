# SUSTech Campus Dashboard

Private local dashboard for SUSTech campus information. The application will use `sustech_survival` to show a daily summary, Blackboard assignment status, TIS exams and pending evaluations, and read-only campus booking queries. Blackboard attachments first seen after activation will be downloaded into course folders under `D:\download`.

The project keeps credentials, downloaded course material, cache, and runtime state out of Git. It will listen on the local machine only.
