# 南科大校园面板

基于固定版本的 [sustech_survival](https://github.com/dumixthestpd/sustech_survival)。支持 Windows 本机客户端和用户自己的 Linux 常开服务器，两种模式共用同一套功能。每个实例独立保存一个用户的凭据和校园数据，直接连接学校系统。

安装与运行见 [客户端说明](CLIENT-README.md)，更新、签名与维护流程见 [UPDATING.md](UPDATING.md)。源码公开，可 fork 后自行部署；凭据、校园数据、运行数据库和下载文件均不在仓库中。

0.3.3 修复公网打印和下载连接：公共入口登录成功后在后台自动配对本机，不重复输入面板密码；组件关闭时也可唤起。“连接当前电脑”保留作重试入口。打印和下载使用同一电脑连接，下载回执同步到网页。下载区域顶部可打开根目录，已保存附件可打开文件或所在文件夹。新版解压后需运行一次以登记 Windows 打开入口；浏览器首次可能提示允许打开客户端。

0.3.0 增加邀请制托管空间：独立 Linux 用户、进程、目录、加密凭据与会话，首批最多 5 人。统一入口 [南科大校园面板](https://124.221.144.155/app/) 直接登录；首次邀请开通也在同一页完成，成功后自动进入个人面板，无需保存个人空间地址。可证明一致的公共信息合并刷新；课程目录仍逐人核验权限，已授权元数据用公共对象与个人引用去重。附件通过学校官方入口或自己的本机组件直接下载，云端不读取或转发文件。实现、验收与运维以 [第一阶段交付记录](docs/HOSTED-PHASE1.md) 为准；原路线见 [Web 托管试用计划](docs/WEB-HOSTED-PLAN.md)，后期本机连接与迁移见 [本机模式衔接说明](docs/LOCAL-MODE-HANDOFF.md)。

## 每日概览与课表

- 显示今日课程、校历放假及调休安排、未提交作业与剩余时间、考试和待评教。
- 调休信息之后提供默认折叠的本周课表：七日网格、课程颜色、教室、节次、实际时段，保留周末补课。
- 校历由 [sustech-calendar](https://github.com/dumixthestpd/sustech-calendar) 的日期引擎计算。假期、停课日与期末期间不显示常规课程，补课使用对应原日期的周次与单双周；校历失败时显示未知，不退回普通星期推断。
- Blackboard 限定 2026 年 9 月起的当前课程。读取失败保留最近成功数据并显示错误。

## Blackboard 作业

每条作业均可展开，显示描述与要求、教师附件、允许尝试次数、提交记录、成绩和反馈、官方页面可读信息与接口元数据。已提交附件从官方提交页面提取，可经私人接口下载。

普通个人作业在官方允许提交时提供拖拽文件框、正文、注释和右下角提交按钮。每次最多 20 个不同文件名的文件，总大小不超过 255 MB。点击提交使用同一登录会话中新读取的官方提交表单与 nonce；不重试写入。只有提交状态及所选文件均回读匹配才确认成功。网络或回执不明确时锁住重复请求并显示待核对。

已提交作业不会覆盖；官方已有草稿附件时保留草稿，提示到原页面继续。测验和小组作业显示可读信息并链接官方页面，不使用个人作业上传入口代替答题或小组提交。页面本身不判断文件是否符合教师要求。

## 场地与预约

- 主页面统一列出图书馆及 E-Hall 场地；可预约场地提供按钮，进入同一架构的下一层页面。
- 讨论间合为一个入口，详情页按官方容量 **1–3 人 / 3–7 人** 分两栏。查询今天至后天的开放与占用安排。
- 可先指定日期和完整目标时段，筛选全程空闲场地，再选房间。改查询时段会使旧查询失效，提交前重新检查。
- 可搜索共同申请人，本人自动加入；按官方人数、开放时间、单次时长与提前预约规则校验。
- E-Hall 使用官方活动类型和活动方式字典，支持申请资料附件。空闲以官方实时检查为准，占用清单仅含当前账户可见记录。
- 我的预约支持日期与官方状态查询，按可用权限显示取消、修改、提前结束、续时等操作。续时先查询官方允许时长；写入回读后才确认，需审批的预约仍以官方审批结果为准。
- **讨论间后台监控已撤销**：独立服务停止且禁止开机启动，旧监控 API 返回 410。已有预约不受影响。

## 课程附件

按课程查看；网页先打开学校下载指引。学校会话失效时在官方内容页登录，再下载到浏览器目录。自动按课程归档、批量下载和失败重试由自己的本机组件完成，组件用本机校园凭据直接连接学校。

自动模式在后台每 5 分钟扫描新可见附件，加载到新附件后加入下载队列。首次启用的 58 项附件 ID 基线保留，自动模式只补下载此后新可见资料；手动全部下载包含旧附件。尚未开放目录显示访问限制，之后开放时算新可见资料。

文件组织为 `D:\download\<课程名>\<Blackboard 目录>\<文件名-稳定ID后缀>.<扩展名>`。代理原子保存并记录大小与 SHA-256；重复任务核验已有文件，用户修改过的文件不覆盖。本机关机时任务留在云端队列，下次登录补下载。页面分别显示入队、下载中、成功或失败；代理不在线时不会伪报本机已下载。

## 成绩、打印、选课与空闲教室

- 首页三个统一入口：成绩与学分、校园打印、选课辅助。空闲教室归入场地与预约。
- 成绩保留 2026 年 9 月起的记录，提供学期筛选、课程搜索、在修学分、通过学分和 CSV 导出。参考 GPA 优先使用 TIS 返回值；等级、百分制、通过制及重修按学校学生手册区分。未知计分制、特殊成绩不冒算官方累计 GPA。
- 打印提供打印点、待打印和扫描文档、按日期和类型查询使用记录，以及文件上传、份数/色彩/纸张/单双面/页码设置。删除先显示文档名和不可恢复说明；上传及删除回读官方队列后确认。文件只在请求期间暂存，结束即清理。**PMS 仍受校园网或学校 VPN 可达性限制；2026-10-07 本机实际只读查询成功，公网请求由所属执行电脑处理。网络受限时会明确显示未连接，不能冒充空队列或成功上传。**
- 选课支持全校目录与本人本轮可选课程、教师/类别/语言筛选、已选课与官方购物车、按周次和节次检测冲突、最多八门课程的备选排课，以及使用同一放假/调休规则的已选课 ICS 导出。跨年校历不可用时仅导出已知年份，在文件名及页面中标注截止日期。页面核对后可选入、退课、增删购物车和逐课程更新积分；提交前重查窗口与权限，不忽略冲突和容量规则。每次写入只发一次，官方记录未匹配时保留待核对状态。
- 空闲教室按日期、节次、地点和已知容量筛选；假期抑制常规课程，调休使用原课程日期。临时借用按实际日期处理。教务系统不返回场地编码时显示“借用待核验”，不能把上游空数组当作已确认空闲；借用申请保留学校入口。
- 新接口按需读取，不阻塞首页 Blackboard 和资料同步。未验证正式选退课、积分更新、打印上传或删除；这些操作只在用户点击并核对后执行。

## 运行与存储

```powershell
pwsh -NoProfile -File 'D:\Projects\SUSTechCampusDashboard\dashboard.ps1' start
pwsh -NoProfile -File 'D:\Projects\SUSTechCampusDashboard\dashboard.ps1' status
pwsh -NoProfile -File 'D:\Projects\SUSTechCampusDashboard\dashboard.ps1' bookings
```

Windows 的 `start` / `serve` 命令启动本机客户端，`open-server` 打开已配对服务器。旧 Windows 登录任务 `SUSTechCampusDashboard` 已在从零重建时停用；0.3.3 普通客户端支持从已登录网页唤起并连接打印、下载。本机数据位于 `D:\AppData\SUSTechCampusDashboard`，依赖环境在 `D:\Caches\SUSTechCampusDashboard-venv`。凭据使用 Windows DPAPI，仅在当前用户进程内解密。

原拥有者实例曾使用 `sustechmon`、`/var/lib/sustech-room-monitor/dashboard` 和签名客户端启动器。2026-10-07 用户要求从零重建后，该服务及本机下载组件已停用，旧记录进入私密恢复区；`/campus/api/` 返回 410。当前从统一公共入口通过新邀请创建独立托管空间，尚未开通的新空间不继承旧会话、凭据、快照或下载基线。实际状态与验收见交付记录；旧讨论间监控继续停用。

运行快照、凭据、基线、下载资料、数据库及日志均不进入 Git。上游固定提交 `acd20323af6d3bc91c3e89974283d39d85109678`。
