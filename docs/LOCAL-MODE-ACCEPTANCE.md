# 第二阶段实施与验收

更新：2026-10-11。**真实数据迁移、静态发布页切换、运营者托管退役及服务器续签迁移已完成。**本页保留该阶段的迁移证据，范围以 [总计划](WEB-HOSTED-PLAN.md) 为准；本机清空重装、网页入口与静默运行见 [0.4.1 历史验收](RELEASE-0.4.1-ACCEPTANCE.md)。当前版本和独立 Windows 的分发、登录、下载及更新状态以 [0.4.3 验收](RELEASE-0.4.3-ACCEPTANCE.md) 为准，不能以同账号重装代替独立 Windows 验收。

## 已实现

- 默认本机启动；受限 `sustech-campus://open`，已有实例须通过令牌证明和就绪检查才交给浏览器。旧运营者配对在读取密文凭据和联网前拒绝，个人服务器配置保留。
- Windows 当前用户 Inno Setup 安装器、快捷方式、可选登录后后台启动；卸载保留数据，并核对注册项归属及当前命令后清除。安装器尚无 Authenticode 签名。
- 首页和设置页共用更新组件，处理下载、等待任务、重启重连、成功和回退；新安装器不会因旧版本指针而启动较旧程序。沿用原 TUF 根和 ZIP 更新目标。
- 迁移工具只导出业务文件，按本人有效授权展开共享引用；独立核验目标学校账号，合并基线与操作账本，逐文件核对下载哈希。未知结果保留待核对，迁移初始暂停自动下载；凭据不进入通用迁移包。
- 发布页源码与构建器已实现，内容为下载、已安装唤起与帮助；没有账号登录或个人数据读取。
- 旧托管入口的执行命令、新建托管/邀请及旧升级命令已禁用；历史模块仅保留用于取证与回归。服务器对应业务服务、账户、凭据和独占状态已移除。

## 未完成
