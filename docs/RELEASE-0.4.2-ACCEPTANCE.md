# 0.4.2 分发与 Windows 兼容验收

历史记录：2026-10-11。0.4.2 已由 [0.4.3](RELEASE-0.4.3-ACCEPTANCE.md) 接替；本页保留其路径修复和阶段验收证据，不能作为当前下载版本已通过独立 Windows 全流程的依据。

## 修复与通用性

- 新 Windows 用户使用自己的 `%LOCALAPPDATA%\Programs\SUSTechCampusDashboard` 安装目录、`%LOCALAPPDATA%\SUSTechCampusDashboard` 数据目录和用户 Downloads 下的 SUSTech 目录。存在 D 盘不再改变默认路径。
- 仅当旧 `D:\AppData\SUSTechCampusDashboard` 存在且其 Windows 所有者为当前用户时保留旧数据与下载默认目录。所有者使用 Windows 原生 API 比较，没有硬编码开发者用户名、账号或 SID。
- 用户明确配置的数据或下载目录仍优先。旧安装路径由安装器原有机制保留；测试脚本也恢复完整卸载注册信息，避免临时安装验收改变真实安装入口。
- 源码和发布包检查未发现开发者用户路径、校园所有者标识或私密运行文件。实际包包含 Python，不要求朋友安装 Python 或 PowerShell 7。

## 独立 Windows 10

使用官方 Windows 10 Enterprise LTSC 2021 评估镜像与 QEMU 隔离虚拟机，标准用户 CampusTest，C 盘用户目录，无外部 Python、PowerShell 7。Docker Desktop 未能提供可用引擎；WHPX 曾出现系统崩溃，改用 QEMU TCG 后完成下列实际流程。

- 从公共页下载并正常执行 0.4.1 安装器，自动启动客户端与浏览器；空实例没有继承原电脑凭据，首次校园 CAS 登录和真实同步通过。
- 取得 5 门课、11 项作业、56 个附件，正常下载一个 213,581 字节附件，文件哈希与真实回执一致。
- 实际 0.3.5 程序使用该实例数据，通过公共签名源升级至 0.4.1；无需重登，下载文件哈希保留。该轮完整私密文件升级前基线未持久化，因此不声称所有私密文件逐项哈希均已比较。
- Windows Shell 实际桌面快捷方式启动成功，目标与进程路径匹配。此 Windows 的 WScript.Shell 读取产品快捷方式 TargetPath 返回空，保留这个读回失败；使用快捷方式二进制路径与实际 Shell 启动分别核实，未修改产品快捷方式来迎合测试。
- Windows 正常关机事件 1074、6006 已确认，期间完成 .NET 更新。重启后的启动、数据保留及 0.4.2 最新公开安装流程待验收结果。
- 重启后 0.4.1 标准用户自启动、无自动浏览器弹出、凭据与真实附件哈希保留、桌面启动和 Windows 协议 Shell 调用已通过。随后真实 0.4.1→0.4.2 签名升级通过，升级前基线已持久化并逐项比较。
- 正常退出后的卸载观察曾因一个旧 0.4.1 协议进程显示异常对话框而超时。已通过隔离系统的 UIAutomation 确认异常窗口并正常关闭；该异常的具体原因未捕获，不以推测的 D 盘原因代替证据。后续须用 0.4.2 启动器重新验证打开及退出。
