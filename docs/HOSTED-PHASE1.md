# 托管第一阶段：实现与验收

日期：2026-10-07。版本：0.3.1。当前状态：第一阶段 P0–P4 已开发、部署并通过验收；公共入口为 `https://124.221.144.155/app/`，5 个未绑定试用空间已就绪，尚未发送邀请。拥有者 `/campus/` 已升级且原会话、58 项基线与写操作记录保持。本文为第一阶段现役记录，原设计保留在 `WEB-HOSTED-PLAN.md`。

## 已锁定的试用边界

- 首批上限 5 人，独立 Linux 用户、进程、私密目录、凭据与会话；使用现有 HTTPS 站点的 `/app/` 入口和 `/spaces/<随机ID>/` 空间。
- 共享元数据数据库上限 256 MiB；每实例私密状态上限 128 MiB。写操作账本不自动删除；配额满时暂停新增并提示。
- 旧元数据最多 2 版且不超过 7 天，脱敏服务日志 14 天/总计 32 MiB；验证完成的恢复备份保留 7 天，由 `campus-hosted-retention.timer` 每小时检查，并在升级时检查。清理只匹配本项目指定恢复目录、任务前缀与 verified 标记，保留未验证备份和个人活动数据。退出先撤销会话、任务和共享引用，个人材料删除另行处理。
- 每实例 CPU 50%、MemoryHigh 256 MiB、MemoryMax 512 MiB、TasksMax 64；共享服务内存 192 MiB、CPU 30%。这些是限制，不是五个高负载用户同时使用的容量承诺。
- 作业上传仍受 256 MiB HTTP 上限约束，认证子请求使用同样上限。打印上传沿用 50 MiB、每实例一项未完成写入及完成/超时清理规则；它与附件下载是不同的数据流。

## 已实现

- `execution.py` 区分本机、个人服务器和托管环境，兼容原 CLOUD 配置。
- 维护者 CLI 只为登记的随机实例生成固定端口、systemd 服务和 nginx 路由，不接受任意后端 URL。数据目录逐用户 0700，共享程序由 root 管理。
- 邀请限时 24 小时、单次使用、绑定空间，数据库只存摘要；令牌放 URL fragment，页面读入后立即清除，不进服务器请求和 Referer。邀请文件仅维护者可读，不自动发送给朋友。
- 网站访问密码保存 scrypt 哈希；实例独有 Cookie 名称/作用域与会话数据库。重启保留会话，退出撤销当前会话，更换密码撤销旧会话。
- 已登录空间在明确同意托管说明后验证 CAS。保存选项默认关闭；选择保存时使用 `cryptography.Fernet` 加密，独立密钥通过 systemd credential 注入。密钥与密文分开，不把 CAS 放进环境变量或命令行。
- systemd credential 保持为稳定解密密钥，可替换的 CAS 密文在实例数据库中，因此更新密码不依赖写入不可变的运行时 credential。空间终身绑定同一校园身份；断开停止同步并清除密文。
- 共享 SQLite 服务以各实例独立令牌认证。字段白名单、批量/单对象/引用数量限制、过期授权、原子版本发布、刷新租约、失效通知、304、失败退避和过期执行者拒绝均已实现。
- 快照将课程公共字段、作业公共字段及附件目录转换为共享对象引用，个人截止例外、状态、成绩、历史和偏好保持本地。
- 已验证公共天气可以合并读取。Blackboard 课程仍先逐人读取权限与可见目录，然后去重规范化存储；没有证据证明相同权限时不合并抓取。教师说明、个人化页面和官方提交详情仍按个人读取，未把整份 HTML/JSON 放进共享缓存。
- 首次成功扫描为新空间建立自己的基线，不复制拥有者原基线。纯 Web 定时发现新资料，打开下载指引不标记保存完成；自动文件任务由自己的下载组件处理。
- 云端附件路由提供官方内容页/下载地址，本机组件使用本机 CAS 会话连接学校。云端不请求文件字节、不建立附件缓存、不打包或流式转发文件。
- 本机回执保留大小、SHA-256、来源元数据版本。元数据变化时另存版本文件；用户修改的旧文件保留。学校没有可靠内容版本且静默替换同名同大小文件时，元数据指纹无法证明字节是否变化，不冒称附件内容哈希。
- 托管用户不能安装共享更新或停止服务。维护者升级先取得一致性备份，再逐实例启动和健康核验；失败恢复原程序，不重放学校写操作。

- 两个真实 Linux 服务使用独立用户和目录；验证邀请重放、Cookie 改名串用、伪造代理头、跨目录读取、下载任务串用、打印队列隔离、停止 A 后 B 正常、重启会话保持、改密码撤销。

## 运维入口

维护命令只在服务器本机以 root 执行。当前 `<release>` 为 `/opt/sustech-campus-hosted/releases/0.3.1`；命令的 `PYTHONPATH` 指向该目录的 `src`。Python 为 `/opt/sustech-campus-hosted/venv/bin/python`。

- 开通：`deploy/hosted_admin.py create --host 124.221.144.155`。超过 5 个活动空间拒绝新增。命令只输出空间与私密邀请文件路径。
- 未使用邀请续期：`deploy/hosted_admin.py invite <space-id>`；激活后不能重放或重新邀请覆盖账号。
- 撤销：`deploy/hosted_admin.py revoke <space-id>`，随后运行 `deploy/hosted_routes.py` 更新登记路由。个人数据保留，其他人的共享引用不受影响。
- 更新登记路由：`deploy/hosted_routes.py`，保存旧 nginx 配置、校验后热加载；失败恢复原配置。拥有者 `/campus/` 路由保留。
- 托管升级：`deploy/hosted_upgrade.py --program <release>`。一致性备份包含实例、共享数据库、配置与 systemd 密封凭据；排除附件/打印文件本体。不同数据格式的降级不自动执行。
- 诊断：`systemctl status campus-metadata 'campus-space@<id>'`；日志使用 `journalctl --namespace=campus-hosted`。不要输出私密数据库正文或凭据。
- 保留检查：`systemctl status campus-hosted-retention.timer`；手动检查可运行 `deploy/hosted_upgrade.py --collect-only`，不会操作活动数据目录。
- 个人服务器及 Windows 分发仍使用原 TUF 更新流程。安装包更新不能替代下载组件运行版本验收。

本地验收汇总与截图保存在 `D:\Artifacts\SUSTechCampusDashboard\hosted-phase1\`。下载验证原件存放在该目录下受限的 `private-…` 子目录，不进入 Git、安装包或公开更新源。

## 仍须区分的边界

- 两个 fixture 和 10 路并发验收不能替代朋友真实账号的首次使用；朋友首次绑定由本人完成，验收只允许读取和附件下载。
- 5 个未绑定实例的基础负载不代表同时进行大文件上传的峰值。实际试用中达到资源/磁盘限制时停止扩容，不承诺更多用户。
- 学校未提供已核实的跨用户轻量权限证明，课程目录的个人权限请求仍逐人执行；共享命中不能暴露其他人是否选课。
- 不提供本机强隐私页面连接或完整迁移工具；它们仍属于后续阶段。路径隔离不是浏览器同源隔离，学校 HTML 沿用严格清洗。
- TLS、服务账号、进程和目录隔离不构成对宿主机管理员不可读的承诺。当前 systemd 宿主密钥所在磁盘并非加密介质；管理员信任边界已在托管说明中披露。
- 未向朋友发送邀请，未执行真实测试作业、预约、选退课或打印。测试实例、构建产物和失败包留作复核现场，不作为用户空间复用。
