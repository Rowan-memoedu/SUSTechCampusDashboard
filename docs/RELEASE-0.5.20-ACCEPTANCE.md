# 0.5.20 直接访问与作业同步修复

## 行为修复

- 本机访问 Cookie 改为 180 天有效并在已认证访问时续期，已有临时 Cookie 自动升级。保留 HttpOnly、SameSite=Strict、Host、Origin 和 CSRF 校验，令牌撤销后旧 Cookie 无效。
- 每次 Blackboard 读取继续使用上游提供的独立 Session，仅串行更新共享登录缓存。整轮作业同步、附件扫描与作业详情不再互相占用长时间的同一把锁；详情同时最多读取两份，避免慢请求占满 HTTP 服务线程。
- Blackboard 读取遇到会话过期时恢复登录并重试一次 GET，提交 POST 不重放。读取减少重复的学期查询与历史课程查询，缩短失败请求等待。
- 后台每 5 分钟同步，页面增加“立即同步”；页面重新可见或网络恢复时检查更新。并发同步请求合并，作业与课表完成后分别发布结果，显示各来源的成功更新时间。
- 浏览器读取有超时和重新读取入口，不再无限停留在加载中。正式提交仍由用户主动操作，本次没有向学校提交作业。
