## 修复与通用性

- 新用户默认安装至 `%LOCALAPPDATA%\Programs\SUSTechCampusDashboard`，数据位于 `%LOCALAPPDATA%\SUSTechCampusDashboard`，附件进入用户 Downloads 下的 SUSTech。存在 D 盘不再改变默认路径。
- 仅当旧 `D:\AppData\SUSTechCampusDashboard` 存在且 Windows 所有者为当前用户时保留旧数据默认目录；用户明确配置的目录优先。Windows 原生 API 比较实际所有者，没有硬编码用户名或 SID。

- 源码与包审计未发现开发者用户名、个人源码路径、校园账号标识或运行数据；关键发布代码与当前源码逐项哈希一致，包内含 Python 运行时。
