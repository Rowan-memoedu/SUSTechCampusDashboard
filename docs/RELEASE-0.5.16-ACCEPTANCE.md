# 0.5.16 Windows 发布验收

## 修复

- 在 0.5.15 修复阶段误停后，真实作业的独立审核发现部分作图题只给了文字步骤、没有实际答案图。英文生产现在逐题检查 draw/sketch/plot 等要求，使用确定性绘图工具生成 PNG 并嵌入对应 Solution，实际核查图形后才完成本阶段。教材原图、坐标表和映射数组不能代替所求答案图。
- 独立源题/解答审核直接接收全部来源页及英文稿引用的图片，核对方向、比例、坐标、标签、分量分解和映射关系，并检查实际图片覆盖清单。
- 英文生产或独立解答审核失败时，完整归档候选，再移除当前英文稿和依赖它的译文，从冻结题面与审核反馈重新生产。已通过的教材、题面和原题配图保留，失败候选不会被人工补丁改成通过。
- 保留 0.5.15 的阶段边界与提取归档，以及既有编译器自动发现、首次双确认和宽松的科学翻译验收。三册核心脚本保持不变。
