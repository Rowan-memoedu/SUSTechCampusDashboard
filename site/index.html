使用帮助

点击打开后无法连接或需要访问凭证

请从桌面或开始菜单打开“南科大校园面板”，它会启动后台并在浏览器中打开有访问权限的本机页面。网页按钮只访问正在运行的后台，不负责启动应用。如果尚未安装，请先下载安装包。

安装时出现安全或信誉提示

请核对下载来源。本项目安装包尚未进行 Windows 代码签名，不要关闭安全检查。若系统不允许安装，请保留提示并通过项目问题页反馈。

账号、课程资料保存在哪里

个人页面由当前电脑提供。校园账号、课程与操作记录保存在自己的运行端，课程附件由它直接从学校获取。此发布网站不接收校园账号或私人资料。

本机“本机与更新”页面会显示数据与资料目录。卸载程序默认保留个人数据和已下载文件。

关闭浏览器或电脑之后还会同步吗

关闭浏览器后，后台组件可以继续同步。退出组件、关机或断网时会停止；再次启动后恢复。可在安装时或本机设置中选择登录 Windows 后后台启动，默认不弹出浏览器。

旧公网登录和空间去了哪里

运营者业务托管已退役，公共站点不再提供账号登录、校园数据查询或任务队列。已有用户请升级本机组件；迁移记录与未完成事项由维护者单独核对，不会自动重放学校操作。

手机和其他设备能用吗

当前分发包面向 Windows x64 与 Ubuntu 24.04 x64。请在安装组件的电脑上打开面板；手机上的此页面不能唤起另一台电脑。
