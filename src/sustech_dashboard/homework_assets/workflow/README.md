# Homework 制册工作流

新窗口从 [工作流入口](../工作流入口.md) 开始。这里维护业务规则；[执行手册](执行手册.md) 维护实际命令和证据结构，两者不保存会话流水账。当前已登记作业以 `../homework_sets.json` 为准，文件入口见 [文件总览](../文件总览.md)。

## 工作流范式

以一次 homework 为固定工作单元，把原件、冻结题面、候选解答、接受记录和最终交付分开保存。AI 承担需要理解的工作，脚本承担可重复的检查和文件处理。每个阶段都有输入、输出和通过条件，完成状态来自当前文件与审核证据。

| 阶段 | 输入与输出 | 通过条件 |
| --- | --- | --- |
| 确定范围 | 作业截图／清单 → 有序 homework 清单 | 不漏题，不把两个独立 homework 合并 |
| 定位原题 | 教材／附件 → 版次、页码、原页图及哈希 | 章节、题型、题号、相邻题和跨页关系已核清 |
| 冻结题面 | 原页 → `题目.md` 和必要原图 | Codex 原页核读、独立图像复核、题号结构检查通过 |
| 英文生产 | 冻结题面 → 英文候选和 `答案册-英文.md` | 完整回答全部分问，独立验算和证明条件检查通过 |
| 专用翻译 | 英文生产稿 → 中文候选、选择记录、`答案册.md` | 公式／段落／图／术语保真，中文语义审核通过 |
| 排版编译 | 冻结 Markdown → 三份 TeX、PDF、日志 | 内容未被排版过程改写，编译无缺字或越界问题 |
| 最终审核 | PDF 本体与逐页渲染 → 哈希绑定的审核记录 | 题号、正文顺序、版式、全部页面的视觉检查通过 |
| 交付 | 已核验 PDF → 课程分类目录、可选双册副本、ZIP | 文件布局、页数、源件与副本哈希一致 |

执行失败时保留原始响应与原因，修订通用 Prompt、工作流或验证器，再从冻结输入重跑。相关方法改变后用失败案例及至少一个独立 Canary 复验。不得手改候选后宣称自动流程通过，不用期望答案提示生产模型。

## 已锁定的交付规则

- 一次 homework 是一个交付单元，篇幅只决定页数。物理每个独立 Ch 作业分别制作；线代同一次 HW 包含的多个小节放在同一个单元。不能按截图数量或学科直接合订。
- 整体题目清单型课程按用户已确定的范围分组；Calculus I 既有分节、周、章合订属于现有数据，不能仅凭课程名新增、拆分或合订。
- 每个单元保留 `题目.md`、`答案册-英文.md`、`答案册.md`、三册 PDF、来源和审核记录。完整 ZIP 留在制作层。
- 题目册保留原题语言、完整题干、全部分问、公式和必要原图，仅供查阅。默认两题一页，长题可由 `questions_per_page=1` 调整。
- 作答册是填写后上传的文件。每题两页；第一页上方作图区、下方过程书写区，第二页只有横线。三个模块题号顺序一致，作答页不放姓名、学号或身份填写栏。
- 本批与以后统一命名为 `课程前缀_homework标签_题目册.pdf`、`…_作答册.pdf`、`…_答案册.pdf`。不恢复姓名学号占位格式。英文课程名在目录、文件名、页内标题保持英文。
- 答案册每题先放完整题目描述，再放 `Solution`。先生成并核验英文题面和答案，再使用专门入口译为保留英文专业表达的中文；专业词、公式和标签不额外加中文释义。保留英文生产稿供用户取得。
- 原中文附件先保存一份经核验的英文题面供英文生产及翻译；最终中文答案册恢复附件的原中文题面，避免回译改变题意。
- A4、18 mm 边距，沿用统一字体与层级；答案按实际长度分页。可以调整受支持的间距，不能把宽公式缩成不可读小字来掩盖溢出。

## 文件输出

默认输出根目录为 `D:/Artifacts/Homework/2026-Fall/output`；用户另行指定时以其当前路径为准。课程类型与模块目录读取 [output-layout.json](output-layout.json)。

```text
output/
  课程名/
    题目/课程前缀_homework_题目册.pdf
    作答/课程前缀_homework_作答册.pdf
    答案/课程前缀_homework_答案册.pdf
  对外发布/
    课程名_homework/
      课程前缀_homework_题目册.pdf
      课程前缀_homework_作答册.pdf
```

三册在课程下对应目录平铺。`homework_copies=true` 才建立本地“对外发布”副本，里面恰好两份 PDF，不含答案册；当前物理和线代为 true，Calculus I 为 false。课程名与 PDF 前缀可以不同，例如目录为“大学物理（上）”、文件前缀为“大学物理上”。

Markdown、图、脚本、日志和核验记录不进入最终 PDF 目录。登记过的衍生合订本以 [output-derivatives.json](output-derivatives.json) 为准，不能删除或覆盖。文件内容与原交付哈希不同可能是用户手写，禁止盲目重交付。“对外发布”只是本地文件夹，不授权任何对外发送。

## 多轮审核及自动化边界

早期人工审核 Markdown 的 Canary 节点已经取消。后续由 AI 审核通过后直接推进，无需用户重复批准。确实缺资料、不能辨认或有影响结果的歧义时，明确报告并保留未完成状态。

1. **原件核读。** Codex 对照原页核查数字、符号、上下标、单位、图、分问和教材版次。文本提取只用于定位；共享段落和跨页题干一起检查。
2. **独立图像复核。** 实际传入原图并做能力 Canary，逐题检查候选题面。`unresolved` 不能改写成通过；整页不可读时补局部图和章节上下文。
3. **结构审查。** 清单、题目、答案的 ID 集合、数量与顺序严格相同；英文教材题面与英文答案题面逐段一致；中文附件核对英中数学及语义对应。
4. **答案审查。** 独立建模、计算和回代；检查所有中间式、分母假设、参数情况、物理方向和量纲。证明题单独检查量词与逻辑前提。
5. **翻译审查。** 固定使用 `D:/Artifacts/TranslationPrompts/translate.py` 的专门规则。可选择 Flash 思考模式；选择依据是实际质量，不是旧模型名。保持每题完整上下文和源文保护区，结构校验通过后仍检查语义。
6. **最终 PDF 审查。** 读取 PDF 本体并检查所有渲染页；代码可核对哈希和覆盖范围，不能自动完成视觉判断。AI 实际审核后填写 `review/codex-review.json`，脚本才记录签收。

任何被审核的源文、候选、译文、证据或 PDF 改变后，相关旧结论失效；按依赖关系从受影响阶段续跑。交付脚本仅复制核验字节，不代表它重新核验了数学。

## 可复用的错误检查

- 题号边界只识别独占一行的 `### Problem <数字与点>`，不把题干内交叉引用当成题号。题号以 homework 目录为作用域，不能全局按裸题号匹配。
- 图题用整页定位、局部图核读；实际刻度、端点、方向、实心点与单位共同判定。图像模型失败不能用它的自报 PASS 覆盖原件。
- 数学证明检查原对象和辅助对象的条件，不能无理由传递连续性、非负性或可逆性。数值验证不能替代一般证明。
- 教材疑似错误或隐含假设在题目册保留原文，在答案中说明采用的解释；不静默改写条件以得到熟悉结果。
- 只允许无语义变化的格式归一，如数学分隔符；失败候选和原始响应保留。超宽、缺字、孤立续页等排版问题通过通用规则调整后重新编译、重新看图。
